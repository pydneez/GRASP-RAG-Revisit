What is GRASP-RAG?

Graph-Retrieval Adaptive Structured Path RAG is a knowledge-graph-based retrieval-augmented generation system. A lightweight LLM classifier assigns each query to one of four structural motifs, then retrieves the appropriate graph subgraph for context.

(a) Ego-Network
Single-entity queries — neighbours of one anchor node
(b) Bridge Path
Two-anchor queries — find intermediate bridge entity
(c) Steiner Tree
Multi-entity queries — min-cost spanning subgraph
(d) PPR Diffusion
Broad queries — Personalized PageRank diffusion
Key finding: GRASP achieves 87.5–100% BER (Bridging Entity Recall) across four domains — yet loses 78% of LLM-as-judge comparisons. This exposes a length bias in LLM judges that favours verbose over structurally precise answers.

The Paradox
GRASP-RAG achieves 100% BER on Agriculture (finds every bridge entity) — yet loses 78% of LLM judge comparisons against NaiveRAG. Bridge queries are the worst: 2W / 47L / 1T despite perfect structural retrieval.
Root cause: LLM judges reward length and comprehensiveness. GRASP's step-by-step PGR answers are precise but shorter than NaiveRAG's verbose, encyclopaedic responses.

PGR vs Flat Context

Path-Guided Reasoning places every entity and connection at a labelled step, making the bridge node structurally unavoidable for the LLM.

Key insight: Flat retrieval (PathRAG / LightRAG / NaiveRAG) gives the LLM correct passages about each anchor but no explicit chain topology. The bridge entity can be omitted without breaking surface fluency. PGR's step-by-step structure forces the LLM to reference the bridge node at a labelled step — making a miss structurally visible and unlikely.

How Path-Guided Reasoning Works

PGR is the context-formatting step after graph retrieval. The context shape matches the query shape — each motif gets its own structured scaffold.

Core idea: instead of dumping retrieved passages as a flat list, PGR serialises the graph subgraph into a numbered scaffold that mirrors the graph topology. The LLM prompt then instructs the model to follow that structure — making structural elements (like bridge nodes) unavoidable rather than optional.
